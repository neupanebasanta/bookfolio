# Bookfolio

Bookfolio is a personal digital bookshelf for tracking the books I read, my ratings, reading dates, and personal notes.

## Features

- Add books to your library
- Rate books from 1–5
- Track reading status
- Record start and completion dates
- Write personal notes
- Search and sort books

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- PostgreSQL
- Open Library API
